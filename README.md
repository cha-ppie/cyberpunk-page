\# CYBERPUNK NIGHTCITY WEB

> 夜之城 · 静态前端展示网页 | Frontend Course Project



> 「The city of dreams.」



\## 项目简介

基于原生HTML/CSS/JS开发的赛博朋克主题多页面网站。

包含夜之城世界观、赛博朋克2077游戏介绍、边缘行者专题、图片画廊等板块。



\### 页面列表

\- `index.html` — 首页

\- `edgerunners.html` — 边缘行者专题

\- `game.html` — 游戏介绍

\- `world.html` — 夜之城世界观

\- `gallery.html` — 图片画廊

\- `guide.html` — 指南



\### 技术

HTML5 / CSS3 / Vanilla JavaScript
